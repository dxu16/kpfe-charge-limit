The candidate remains local, not permanently installed or upstreamed.

Implementation
--------------
One qcom_battmgr.c patch,321 insertions/1 deletion. Exact KPFE model/protocol
gate retained; other models retain their existing backend and status path.
Existing start/end threshold ABI and firmware preference storage retained.
Uses system_wq instead of a freezable worker and removes the explicit hard
wake request. CPU handles GLINK activity then returns to idle while user
space stays suspended. No re-suspend daemon and no overriding a user wake.
Only partial-limit/USB-related notifications schedule private policy work.
Healthy live state is checked before synthesizing Full at the selected end;
the hysteresis band reports Not charging. Actual charging/drain, unknown
status, health faults, disabled/native modes or read failures are not masked.
The first version's cached native-enable flag was stale after disabling the
native backend. Final getter reads native-enable directly with other fields.
Teardown disables work synchronously, preventing a late callback requeue.
